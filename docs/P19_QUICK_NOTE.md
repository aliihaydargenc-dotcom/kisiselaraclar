# P19 Quick Note Editor

Hızlı Not basit textarea formundan günlük kullanıma uygun çalışma alanına yükseltildi.

- Masaüstü tool view: max 1320 px
- Sidebar: 300 px
- Başlık: auto-grow, max 108 px, yatay scrollbar yok
- İçerik: min 520 px
- Bold / italic / strikethrough
- Bullet / numbered list
- Checklist / done-reopen
- H2 / link
- Ctrl/Cmd+B ve Ctrl/Cmd+I
- Not seviyesi Aktif / Tamamlandı
- Arama ve Tümü / Aktif / Tamamlandı filtreleri
- Pin, kopyala ve Markdown indir korunur
- Eski localStorage notları completed=false ile geriye uyumludur
